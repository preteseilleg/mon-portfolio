## Project

MonPortfolio — a static portfolio website. HTML, CSS, and vanilla JavaScript only, no framework.

## Conventions

- Design: minimalist, professional, dark background.
- Mobile-first: write base styles for small screens, add complexity via `min-width` media queries.
- Code (variables, functions, identifiers) in English. Visible content (text shown to users) in French.
